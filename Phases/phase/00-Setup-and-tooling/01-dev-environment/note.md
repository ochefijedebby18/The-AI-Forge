## What is Python?

Python is a high level interpreted programming language use on a server to create web applications and it is very easy to learn.

## what is Runtime?

runtime is when a code operates. runtime helps with the execution of codes

## what is compiler?

Compiler is the source code that checked for syntax and translate into machine or intermediate code before running.

## what is terminal?

A computer terminal is a text-based interface or software program that lets you control your computer by typing written commands instead of clicking with a mouse.

## what is version control?

version control is a system that records and manages changes to computer files—primarily source code, documents, or digital assets—over time.

## What is a Development(Dev) Environment? 

A dev environment is the collection of software tools libraries resources and configuration that you need to write, source, test and maintain programs.

## The four layers of dev environment:

### Layer 1: The system foundation

This is the foundation on which the other layers depend.
It includes:
1. The operating system
2. Shell/terminal
3. Git
4. Code editor
5. GPU drivers

### Layer 2: Package Managers

Package managers help install and manage software dependencies.
It includes:
1. uv — Python package management
2. pnpm — Node.js package management
3. cargo — Rust package management
4. juliaup — Julia version management

### Layer 3: Language Runtimes

These allow programs written in different programming languages to execute.
it includes:
1. Python
2. Node.js
3. Rust
4. Julia

Layer 4: AI/ML Libraries

These provide tools and functionality for developing artificial intelligence and machine learning applications.
It includes:
1. PyTorch
2. JAX

## what is Virtual Environment?

A virtual environment creates an isolated space for a Python project.

It also prevents dependency conflicts, keeps project packages separate, allows different projects to use different package versions and makes development more reproducible.
